Pilot 方案

从 6 题 demo set 到 30 题 pilot set，再通过多 agent、多 seed 跑分筛题。

三阶段建设

阶段 1：6 题 Demo Set每个职业 1 题，展示任务包、工具调用、verifier 与报告格式。
阶段 2：30 题 Pilot Set每个职业 5 题：2 easy、2 medium、1 hard。
阶段 3：稳定性筛题每题至少 3 个 agent stack × 3 个 random seed，剔除低信号或高噪声任务。
