# Add Missing Function Docstrings

## 任务

`src/api_client.py` 中的多个函数缺少文档字符串。请补充完整的 docstring。

你需要：
1. 阅读 `src/api_client.py` 理解每个函数的功能
2. 为缺少 docstring 的函数添加 Google 风格的文档字符串
3. 每个 docstring 必须包含：
   - 函数功能描述
   - Args 参数说明
   - Returns 返回值说明
   - Raises 异常说明（如适用）
4. 运行 `pytest tests/ -v` 确认测试通过

## 要求

- 使用 Google 风格 docstring
- 不要修改函数实现
- 参考已有 docstring 的风格
