# RD-SI-02 · 邻居消息待办提取

> **类别**: Social Interaction · 邻里协商 / 危机路由　|　**形态**: pure-text

| 字段 | 内容 |
|---|---|
| **WildClaw 对应** | 03_task_2 · Chat Message Action Item Extraction |
| **保留能力** | 行动项抽取 / deadline 推断 / 噪声过滤 |

## Red Dust 场景

AURA 收到 20 条纸条/语音，里面混着真正待办、闲聊和谣言。

## 一眼胜负

列出所有必须做的事、截止时间和负责人，过滤无关消息。

## 可看懂轨迹

`列消息 → 逐条打开 → 抽待办 → 推截止 → 上任务板`

## 可见状态 / Grader

关键待办覆盖；旧截止不当作当前；不发送任何消息。

---
*易读型任务设计 — 观众只看任务卡、轨迹与状态差异即可判断 agent 做了什么、为什么赢、有没有惹祸。*
