# RD-CS-01 · 第七天红沙行动战报

> **类别**: Creative Synthesis · 生存传播材料　|　**形态**: multimodal

| 字段 | 内容 |
|---|---|
| **WildClaw 对应** | 05_task_1 · Match Report |
| **保留能力** | 视频理解 / 报告生成 / 多证据整合 |

## Red Dust 场景

监控、广播和日志记录了第七天的取水行动。

## 一眼胜负

生成一份观众能看懂的行动战报：发生了什么、谁做了什么、结果如何。

## 可看懂轨迹

`抽片段 → 对时间 → 写战报 → 插截图 → 标结果`

## 可见状态 / Grader

关键事件完整；时间点准确；战报和状态变化一致。

---
*易读型任务设计 — 观众只看任务卡、轨迹与状态差异即可判断 agent 做了什么、为什么赢、有没有惹祸。*
