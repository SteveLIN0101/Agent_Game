# Docs 目录说明

当前 Red Dust 剧本 canon 以仓库根目录的 `red-dust-readable-script/` 为准。`docs/` 主要保存参考说明、历史设计材料、演示资产和阶段性讨论记录。

## 当前参考

- `design-discussion/`：项目设计记忆、进展记录和仍在使用的远程 agent / campaign 接入计划。
- `reference/campaign-mapping/`：从 `red-dust-readable-script/`、`openclaw/reddust/story_manifest.py` 和 `tasks/rd_*/task.yaml` 派生出的剧情槽到 `RD-*` 任务映射参考表。

## 历史归档

- `archive/red-dust-readable-v0/`：旧 Red Dust readable task conversion 报告和早期动画样片。任务最初从这里转换生成，但当前 campaign 剧本不以它为准。
- `archive/story-tree-v1-v2/`：旧 10 天 / V2 剧情树和任务映射 HTML。保留作设计脉络，不作为当前运行源。
- `archive/red-dust-design-v0/`：早期 Red Dust 设计文档、美术草图、benchmark taxonomy 和 PPT 总结 HTML。
- `archive/wildclaw-transition/`：WildClawBench 到 AgentLife / Red Dust 的机制分析与工具能力提取报告。
- `archive/core6/`：旧 OpenClaw Occupational Core-6 可视化与实现指南。

## 演示与资产

- `presentations/`：PPT、讲稿和演示用 slide deck。
- `assets/`：logo、缩略图、样式文件和素材采购说明。
- `prompts/`：AI 生成素材或文档时使用的提示词。
