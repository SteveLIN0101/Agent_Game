## 一、风格定调

### 1.1 核心风格描述

> 60 Seconds! 简笔画/像素风 + WALL-E 可爱机器人造型 + 一点点 Fallout 废土感

不是这些：
- ❌ Cyberpunk 2077 / Cloudpunk 的霓虹赛博风
- ❌ Mr. Robot / 黑客帝国的故障艺术
- ❌ Deus Ex 的写实科技感

是这些：
- ✅ 60 Seconds! Reatomic（玩法直系参考）
- ✅ WALL-E（可爱破旧机器人）
- ✅ Stardew Valley 风像素 + 末日改色
- ✅ 一点点 Fallout 废土感（但不要太脏）

### 1.2 一句话给美术 brief

> "想象一下: 60 秒避难所那种简笔画风格，
>  但所有人物都是可爱破旧的小机器人，
>  外面不是核灾，是电磁风暴，
>  偶尔有蓝色电弧划过紫色天空。
>  不要赛博朋克的霓虹和故障感。"

### 1.3 三个关键参考画面

- **画面 1 · WALL-E 在垃圾堆里整理东西** → 机器人造型 + 末日感 + 不冰冷
- **画面 2 · 60 Seconds 室内场景** → 像素简笔画 + 资源摆放 + 卡通比例
- **画面 3 · Fallout 庇护所 (Vault)** → 屏蔽建筑感 + 灯光 + 工业风

### 1.4 像素分辨率基准

```
单元 tile:    32×32 px (标准像素艺术)
角色:         48×64 px (略高于 tile, 凸显主体)
道具图标:     32×32 px
UI 元素:      可矢量 (SVG) 或 64×64 / 128×128 PNG
放大策略:     1080p 显示 → 整数倍放大 (2× / 3×)
              4K 显示    → 5×-6× 放大
              必须 nearest-neighbor 缩放, 不要双线性
```

## 二、配色规范

### 2.1 主色调（暖色基底，不要赛博紫粉）

```
主背景:
  #2a1f1a  深棕 (避难所内墙)
  #3a2820  暖棕 (地板/家具基色)
  #1a1410  近黑 (阴影/夜晚)

中性色:
  #5a4530  棕黄 (家具高光)
  #7a5e42  亮棕 (重点物体)
  #f5d4a8  肤色 (机器人面部 LED 屏幕底色)

暖色点缀:
  #ff9500  暖橙 (灯光 / 警告)
  #ffd60a  亮黄 (重要物品高亮)
  #ff6b00  橙红 (危险信号)
```

### 2.2 电磁元素的冷色（仅用于电气/数据）

```
冷色（限定使用）:
  #5ac8fa  冰蓝 (电流 / 电池 / 数据)
  #00d4aa  电青 (电磁余波)
  #30d158  绿 (健康指示 / 救援信号)

慎用:
  #ff3b3b  红 (仅严重错误 / 死亡)
  #bf5af2  紫 (仅"幻觉事件"/异常状态)

⚠️ 禁用:
  #ff2d92  亮粉 (赛博朋克专属, 不要)
  #00ffe0  霓虹青 (太赛博)
```

### 2.3 配色比例

```
画面 70% : 暖棕系（避难所基底, 给玩家"家"的感觉）
画面 20% : 中性色（家具 / 角色身体）
画面  8% : 暖橙黄（灯光 / 警告 / 高亮）
画面  2% : 冷色（电流特效 / 数据元素）
```

> 核心原则：避难所是暖的，外面是冷的。

## 四、Unity 方案规格

### 4.1 通用要求

```
渲染管线:    URP (Universal Render Pipeline)
分辨率基准:   1920×1080
像素艺术:    Unity Pixel Perfect Camera 必开
2D 工具:     Sprite Renderer + Tilemap + 2D Lighting
单位:        1 Unity Unit = 16 px (PPU 16)
```

### 4.2 角色与 NPC

```
文件类型:     PNG 32-bit（带透明）
分辨率:       48×64 px 单帧
打包:         Sprite Sheet（每行 8 帧），单 atlas ≤ 2048×2048
导入设置:
  Texture Type:  Sprite (2D and UI)
  Sprite Mode:   Multiple
  Pixels Per Unit: 16
  Filter Mode:   Point ⚠ 像素艺术必须
  Compression:   None
动画:         Animator + Animation Clip
```

### 4.3 场景与 Tilemap

```
基础瓦片:     32×32 px
墙壁瓦片:     32×96 px (3-tile vertical)
打包:         Sprite Atlas
设置:         Pixels Per Unit: 16
```

### 4.4 UI

```
按钮/边框:    9-Slice (PNG, 64×64 to 128×128)
图标:         32×32 / 64×64 PNG
字体:         TextMeshPro
              · 中文: 思源宋体（subset）
              · 英文/数字: JetBrains Mono
              · SDF 模式
HUD:         Canvas → Screen Space Overlay
              Reference Resolution 1920×1080
```

### 4.5 特效

```
粒子系统:     Unity Particle System
材质:         Sprites/Default
预设:
  - 电磁火花: 3 帧 + 短暂喷射 + 重力 0
  - 充电火花: 蓝色 + 持续生成
  - 受伤火星: 橙色 + 0.3s 消散
2D Light:    用于应急灯效果
```

### 4.6 音频

```
格式:        WAV / MP3 / OGG
位深:        16-bit
采样率:      44.1 kHz
导入:
  Force To Mono:  是 (SFX) / 否 (BGM)
  Compression:    Vorbis (Quality: 70)
混音:        Audio Mixer + Master/Music/SFX/Voice 总线
```

## 五、Godot 方案规格

### 5.1 通用要求

```
版本:        Godot 4.x（推荐 4.3+）
渲染:        2D Compatibility 模式 (Web 兼容)
分辨率:      1920×1080
viewport:    width=1920, height=1080
stretch_mode: viewport

```

```
打包:         单文件 sprite sheet 或 SpriteFrames .tres

  Filter:   Nearest（关闭抗锯齿）
```

```
TileSet 配置:
  - 物理层（碰撞）
  - 自定义数据层（资源/触发）
导出:        .tres
```

### 5.4 UI

```
按钮:         NinePatchRect (9-slice) + StyleBoxTexture
图标:         TextureRect / TextureButton
字体:         FontFile (.ttf)：思源宋体 + JetBrains Mono
HUD:         Control 节点 + Container 自动布局
```

## 六、Web 方案规格

### 6.1 通用要求

```
渲染:        PixiJS 8.x（推荐）/ Phaser 3.80+
分辨率:      1920×1080 base，自适应缩放
```

### 6.2 角色与 NPC

```
文件类型:     PNG (透明) / WebP（更优）
分辨率:       48×64 px (1×) + 96×128 px (2× retina)
打包:         必须 sprite atlas + JSON（工具：TexturePacker / free-tex-packer）
```

### 6.3 文件大小预算

```
首屏加载:    ≤ 2 MB
完整资源:    ≤ 8 MB
单图大小:    ≤ 256 KB
优化:
  - WebP 替代 PNG (-30%)
  - SVG 用于 UI（无限缩放）
  - MP3 96 kbps（音频）
  - 懒加载非首屏
```

### 6.4 UI（推荐混合方案）

```
游戏画面 → Canvas (PixiJS)
HUD / 按钮 / 弹窗 → React DOM
优势: 文字清晰、易做交互
字体: Google Fonts（思源宋体 / JetBrains Mono）
```
