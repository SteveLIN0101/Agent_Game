0 · 整体视觉风格定位

参考 60 Seconds! Reatomic + WALL-E + 一点 Fallout 废土感。手绘像素风（不是赛博朋克）。

1 · 主场景：避难所内部（横切面视角）

游戏的核心舞台。横切面视角让玩家能看到避难所"剖面"，类似 60 Seconds 的经典构图。

美术要点： 横切面视角（不是 3D 也不是俯视图）· 一个房间被"剖开"展示给观众 · 家具/物资保留 60 秒原版风格但贴上机器人主题 · 温暖偏暖的房间 vs 外面的冷蓝色 = 视觉对比 · 墙体加 EMP 屏蔽纹理（可加细的 + 字格子图案做 Faraday 笼暗示）。

找素材关键词： "60 seconds bunker", "fallout vault interior pixel", "post apocalyptic shelter cross section", "WALL-E warehouse interior style", "robot workshop pixel art", "Stardew Valley interior".

2 · 8 个 Hero 机器人形象

每个 agent 用机型 + 颜色区分。统一头部圆/方 + 身体方框，但通过装饰元素体现人格。

找素材关键词： "pixel robot characters set", "robot RPG sprites", "WALL-E inspired robots", "Mega Man robot variants", "bit robot character pack", "robot npc pixel art".

免费推荐： Kenney "Robot Pack" / itch.io "Pixel Robot" 搜索 / OpenGameArt "robot sprite". 不强求一次买全 8 个，可以买 2-3 个底模再改色 / 改细节。

3 · NPC 机器人形象

8 个故事 NPC，每个有强烈视觉辨识度。

设计要点： NPC 一眼能看出"职业/身份"。 老家政 = 矮锈球 + 拐杖 · 拾荒者 = 拼接铠甲 + 武器 · 商人 = 推车 + VR · 流浪儿童 = 小 + "NEW" 标签 ·

找素材关键词： "old robot rusty pixel", "scavenger robot post-apocalyptic", "merchant robot npc cart", "tiny robot child sprite", "soldier robot game asset".

4 · 资源道具图标（24×24 / 32×32）

8 大资源类型的图标设计。简笔画风格，色彩饱和度高便于识别。

设计要点： 图标 ≤ 32×32 px · 最多 4-5 个色 · 主体 + 1-2 装饰元素 · 边线 1-2 px 描边便于在背景上看清.

找素材关键词： "pixel item icons set", "RPG resource icons 16x16", "post-apocalyptic loot icons", "battery medical kit pixel", "Kenney game icons".

5 · 外部世界（电磁废土）

通过监控屏看出去 / 派人外出时看到的场景。

美术要点： 紫红色调天空（电磁余波）· 倒下的城市轮廓 · 偶尔的紫色电弧 · 停摆的车 · 散落的报废机器人零件 · 远处偶有一盏黄/红灯（暗示还有其他幸存者）。

找素材关键词： "post apocalyptic city skyline pixel", "wasteland pixel art background", "abandoned city silhouette", "purple sky electromagnetic storm", "ruined urban pixel".

6 · 事件场景示意

3 个典型事件场景的画面布局, 帮美术师理解叙事节奏。

美术要点： 每个事件 = 一张"电影分镜"。主体 + 戏剧化氛围 + 选项提示 · 重要元素始终居中或 1/3 处 · 暗色调 + 1-2 个高饱和点（红色警报 / 黄色警示）。

找素材关键词： "60 seconds event illustration", "comic panel pixel game", "RPG event scene art".

7 · UI 框架元素

游戏内 UI 的边框 / 按钮 / 弹窗风格。复古工业感。

UI 风格要点： 深色背景（#1a1410 棕黑）+ 暖橙边框（#5a4530）+ 角钉细节（致敬复古机械）· 按钮三色区分（绿=积极 / 红=拒绝 / 紫=好奇）· 等宽字体用于数字 / 中文字体用于叙事.

找素材关键词： "retro game UI pack", "industrial sci-fi UI", "Fallout terminal UI", "Kenney UI Pack", "pixel game HUD".
