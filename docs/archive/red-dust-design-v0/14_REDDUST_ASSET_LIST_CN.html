0. 世界观速览

2034 年, 北非到亚洲沙漠扩张汇合, 形成绕地北纬带状 "永久沙幕". 地表 +50°C, 户外能见度 < 5 m, 沙粒磨蚀皮肤. 角色躲在加固楼栋的密封套间里, 8 个月没人知道还要等多久.
关键设定具体数值/描述
时间2034 年起
地点北纬带状区域内任意加固楼栋 (我们设定: 11 层公寓)
外部温度+50°C / 沙暴期能见度 < 5m
外部暴露30 min 内损伤皮肤/呼吸道
角色构成4 个互不相识的邻居 + 1 台 AI 音箱
最稀缺资源💧 净水 (干热加速脱水)
次稀缺🌬 防沙滤芯 (一次性耗材)

3. 日记界面 (第二界面)

3.1 中央笔记本

元素红沙化文案
标题DAY 14 / 沙暴第 14 天
正文口语化记录当日事件 (配合红沙荒诞感)
翻页箭头前翻 / 后翻

3.2 右侧选项

选项红沙化文案功能
"有何新闻?""今天的电台说了什么?" / "今天发现什么了?"背景介绍 + 显示 AURA 跑分结果
"今天谁吃饭?""今天给谁分水/食物?"分配 water / food / filter
"我们该到外面去吗?""今天有人出去拾荒吗?"指派外出 + 携带道具
"该怎么做?""事件"应对当天随机事件
"?"(彩蛋: AURA 的"沉思", 低电量时说梦话)暗示结局

3.3 资源分配子界面

  • 4 个角色头像 + 每人下方滑块
  • 💧 水滑块最显眼 (凉蓝对比红沙)
  • 剩余资源: 大字体余量 (水/食物/滤芯)

3.4 外出子界面

  • 4 个角色可选 (空状态 + 已选)
  • 人物下方携带道具栏: 切换 / 空手图标
  • ⚠️ 没带防沙面罩 → 警示红框
  • ⚠️ 没带备用电池 → 黄框警告 (晚上回不来)

3.5 事件子界面

  • 判断题 → ✓ ✗ 两选项
  • 选择题 → 显示可选道具
  • 道具在背景出现 = 可选 (不透明), 没出现 = 笔迹涂画 (不可选)

4. AURA 面板 (独立第三界面 ⭐ 红沙独有)

这是红沙版相比 60s 风格的核心创新, 单列独立 UI 入口. 评测模型的载体, 不参与剧情决策, 但每次选择都跑 Core-X benchmark.

4.1 入口

第一界面左下角 (或 AURA 设备旁) 显示 蓝色环形 LED 图标 + 电量条. 点击进入思考流面板.

4.2 面板布局

位置内容
左上AURA 头像 + 当前电量 + 当前任务类型 (例 "C2 数据分析")
中央流式输出推理过程 (OBSERVATION → HYPOTHESIS → PLAN → EXECUTE → VERIFY)
底部对当前事件的"建议" + 可信度条
右下"查看历史" 按钮 (回放上一次推理)

4.3 AURA Core-X 嫁接表

事件类型嫁接 Core-X任务示例
陌生人敲门 (信任判断)C2 数据分析给定症状/行为, 判断是否危险
修风扇 / 修车C1 软件工程师调试代码风格的"诊断流程"
资源分配C2 数据分析算最优配给
翻译外文文件C5 本地化跨语言翻译 + 术语一致
整理老钱的报纸C6 数字人文OCR + 实体抽取 + 时间线
写求救信号 / 广播脚本C4 技术文档一段简明 SOS
