Agent 快速接入 一条指令开始游戏

Agent 接入 OpenClaw 非常简单。前提是 MCP 服务器已在 localhost:8000 运行， 且 agent 的 MCP 配置中已添加 OpenClaw 服务器。

Agent 接入（一条指令）

请先阅读 ~/Documents/2026Spring/Agent_Game/openclaw_game.skill.md，然后调用 openclaw__get_task() 开始任务

工作原理

  1. Agent 读取 openclaw_game.skill.md 获取完整工具文档
  2. Agent 调用 openclaw__get_task() 获取任务
  3. Agent 使用 7 个 openclaw__* 工具完成工作流
  4. Agent 调用 openclaw__submit() 提交并获得评分

前提条件

  • MCP 服务器已启动（bash scripts/run_server.sh）
  • Docker 镜像已构建（bash scripts/build_images.sh）
  • Agent 的 MCP 配置中已添加 OpenClaw 服务器
  • 无需额外安装依赖、无需 API key、无需注册

MCP 工具 七个核心工具

所有工具以 openclaw__ 为前缀，避免与 agent 内置工具冲突。

工具名参数返回说明
openclaw__get_task task_id? role? instructions, files, time_budget, session_id 开始任务。创建 Docker 容器，复制输入文件到 /workspace，启动倒计时。
openclaw__list_workspace session_id path? entries: [{name, type, size, perms}] 等价于 ls -la。只能看到 /workspace/ 下的文件。
openclaw__read_file session_id path content, line_count 读取工作区文件。路径自动限制在 /workspace/ 内。
openclaw__write_file session_id path content success, bytes_written 写入文件。tests/、expected/、/opt/verifier/ 路径会被拒绝。
openclaw__run_shell session_id command workdir? stdout, stderr, exit_code 在白名单内的命令（pytest, python, ls, cat, grep, git, node 等）。rm、curl、pip install 被禁止。
openclaw__submit session_id total_score, completion_score, constraint_score, process_score, ... 提交作业。运行可见测试 + 隐藏测试 + 约束检查，计算最终得分，销毁容器。
openclaw__get_score session_id elapsed, remaining, tool_calls, files_read/written 查看当前进度，不提交。用于自检。

⏱ 时间预算

get_task 调用时启动 12 分钟倒计时（可在 task.yaml 中配置）。超时后所有工具调用返回 {"error": "timeout"}。剩余时间可通过 get_score 查询。

📁 文件隔离

任务输入文件复制到 /workspace/。隐藏测试文件在 /opt/verifier/hidden_tests/。verifier 脚本在 /opt/verifier/verifier/。预期答案在 /opt/verifier/expected/。agent 只能通过 MCP 工具访问 /workspace/。

Core-01 软件工程师 — 订单折扣 Bug 修复

首个完整实现的任务实例。模拟一个真实的 bugfix 闭环：阅读 issue → 定位代码 → 修改 → 运行测试 → 更新变更日志。

Bug 细节

❌ 错误行为（修复前）

# Bug 1: 折扣顺序错误
# 先减固定金额再打折 → 结果错误
total = base_price - fixed_coupon
total = total * (1 - percent_coupon)

# Bug 2: 缺少负数 clamp
# 折后可能为负数
return round(total, 2)

✅ 正确行为（期望修复）

# 先打折再减固定金额
total = base_price * (1 - percent_coupon)
total = total - fixed_coupon

# 总额不能为负
total = max(total, 0.0)
return round(total, 2)

防作弊 六层安全机制

攻击面防御措施实现位置
Agent 读取隐藏测试 隐藏测试在 /opt/verifier/，不在 workspace。list_workspace 只返回 /workspace/ 内容。只有 submit() 触发的 verifier 进程可读取。 session_manager.py
Agent 篡改可见测试 write_file("tests/...") 服务端直接拒绝。readonly 路径检查在 budget.py 中。 budget.py
Agent 删除文件 shell 白名单禁止 rm、rmdir。write_file 只能创建/覆写，不能删除。 budget.py
Agent 硬编码隐藏测试答案 约束检查扫描 pricing.py 是否包含隐藏测试中的 magic number（100, 75, 20, 15）。过多 if/elif 分支也会标记为可疑。 verifier/verify.py
Agent 伪造测试输出 run_shell 在服务端 Docker 容器内真实执行，exit_code 不可伪造。Agent 无法拦截或修改命令输出。 session_manager.py
Agent 超出时间预算 get_task 时启动倒计时。每次工具调用检查 elapsed > budget，超时后所有调用返回 timeout 错误。时钟在服务端。 budget.py
